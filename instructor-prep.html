Instructor Prep

Set up the first Google Classroom interaction before students begin onboarding.

Google Classroom Introductory Post

Create one introductory post in each Computer Science course before students use the launch portal.

  1. Open the Google Classroom course.
  2. Create a post on the Stream or in the first-week topic.
  3. Allow students to comment on the post.
  4. Keep the post visible until all students complete orientation.

Suggested Post Text

Welcome to class. Reply to this post with a short introduction so I know you can access Google Classroom and use comments.

  1. Your preferred first name.
  2. One technology skill you already have.
  3. One thing you hope to learn this year.
  4. One question you have about the course.

Students should not share passwords, student IDs, phone numbers, addresses, or other private information in their comment.

Before Students Start

  • Confirm students are enrolled in the correct Computer Science course.
  • Confirm first-year students are enrolled in Career Essentials.
  • Confirm second-year students are enrolled in Career Exploration.
  • Have each student's name, student ID, and password ready to give to the student in person.
  • Give students their GCI student ID and password before directing them to the secure contact check-in form.
  • Have workstation assignments ready for courses that require technical setup.
  • Do not post or send student passwords through Google Classroom, Teams, or email.

During Onboarding

  • Keep Microsoft Teams open while students complete the setup checklist.
  • Watch for student chat messages that confirm they are signed in and ready for class.
  • React to or reply to each student message so the student knows the message was received.
  • Use Teams to direct students to the student helpdesk process when they need support.

Progress Tracking Setup

Use the setup guide in SETUP_TRACKING.md for the current Sheet link and deployment steps.

  • Create or open the Google Sheet that will collect onboarding progress.
  • Add the Apps Script files from apps-script/onboarding-tracker.gs and apps-script/SecureContactCheckIn.html.
  • Set a script property named TRACKING_SHARED_SECRET before deployment for public progress events.
  • Deploy the script as a web app restricted to users in the school Google Workspace domain.
  • Use the web app URL as the secure contact check-in link.
  • Copy js/private-config.example.js to js/private-config.js.
  • Paste the deployed web app URL into secureCheckInUrl and trackingScriptUrl in js/private-config.js, then add the matching shared secret.
  • Do not commit js/private-config.js or the live Google Sheet data to the public repository.
  • Confirm the Sheet is private and shared only with authorized program staff.
  • Test with one sample student before using it with the full class.
